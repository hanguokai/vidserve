# VidServe

VidServe is a simple, lightweight LAN video server and media player. With zero complex configuration, simply select a video folder on your computer and launch your personal streaming website in seconds.

---

## ✨ Key Features

- **🚀 One-Click Setup**: Select a directory, click start, and your local video server is live.
- **📱 Zero-App Cross-Device Streaming**: Scan the generated QR code on your phone or tablet to stream videos directly in any web browser — no client app required.
- **🌐 Sleek Web-Like Interface**: Enjoy a clean, modern streaming experience with intuitive directory browsing and smooth playback.
- **🎵 Smart Auto-Playlists**: Automatically gathers all video and audio files in the selected folder into a continuous, playable list.
- **⌨️ Touch & Keyboard Controls**: Supports full desktop keyboard shortcuts as well as mobile touch gestures for seeking and volume control.
- **🌍 Native Multi-Language**: Built-in support for English, Simplified Chinese, Traditional Chinese, Japanese, German, French, Spanish, and Brazilian Portuguese.

## 💻 Download & Installation

### macOS
1. Go to [GitHub Releases](https://github.com/hanguokai/vidserve/releases) and download the latest `.dmg` file (`VidServe-vX.Y.Z.dmg`).
2. Open the `.dmg` file and drag **VidServe** into your `Applications` folder.
3. Launch **VidServe** from Launchpad or Finder.

## 🔄 How Updating Works

### macOS
VidServe includes an automatic update checker:
- When a new version is published on GitHub Releases, a friendly update banner will appear at the top of your VidServe control panel with a link to download the latest `.dmg`.
- Simply download the new `.dmg` file and drag **VidServe** to your `Applications` folder to overwrite the existing app. All your saved settings will be preserved.

---

## 📖 How to Use

1. **Launch VidServe**: Open the app to display the control panel.
2. **Select Directory**: Click **Browse...** to pick the video folder you want to share (or type the path manually).
3. **Start Server**: Click **Start Server**.
4. **Start Watching**:
   - On Desktop: Click **Open App** button to watch in your browser.
   - On Phone/Tablet: Scan the **QR Code** with your camera to open the web player on your local Wi-Fi.

---

## ⚠️ Known Limitations

1. **Browser Codec Compatibility**: Playback depends on native browser decoding capabilities. Some uncommon video/audio codecs may not play properly in standard browsers.
2. **Subtitles**: External subtitle files (`.srt`) are not supported in the current release and will be added in a future update.
