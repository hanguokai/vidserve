# VidServe

VidServe 是一款极简、轻量的局域网视频服务器与播放器工具。无需复杂配置，只需选择电脑中的视频文件夹，即可一键搭建专属的个人局域网视频网站。

---

## ✨ 核心亮点

- **🚀 极简启动**：无需繁琐设置，选择视频目录，点击启动，秒变个人视频网站。
- **📱 跨设备零门槛**：手机或平板扫描二维码，直接通过浏览器播放，无需安装任何客户端 App。
- **🌐 媲美视频网站的交互体验**：流畅的文件目录浏览与优雅的播放界面，无论在 PC 端还是移动端，都如使用在线视频网站般舒适自然。
- **🎵 智能播放列表**：播放视频时，自动将当前目录下的所有音视频文件整合成播放列表，支持连续播放。
- **⌨️ 快捷掌控**：支持 PC 端桌面快捷键操作与移动端触控手势控制（垂直/水平滑动调节音量与进度）。
- **🌍 多语言支持**：原生支持简体中文、繁体中文、英文、日语、德语、法语、西班牙语、巴西葡萄牙语。

## 💻 下载与安装

### macOS
1. 前往 [GitHub Releases](https://github.com/hanguokai/vidserve/releases) 页面，下载最新的 `.dmg` 安装包（`VidServe-vX.Y.Z.dmg`）。
2. 双击打开 `.dmg` 文件，将 **VidServe** 拖入 `Applications`（应用程序）文件夹中。
3. 从 Launchpad 或 Finder 中启动 **VidServe** 即可使用。

### Windows
- **Microsoft Store**：直接从 [Microsoft Store](https://apps.microsoft.com/detail/9P8MP5C6DHKJ) 下载安装。

## 📖 使用指南

1. **启动应用**：打开 VidServe 显示控制面板。
2. **选择目录**：点击 **浏览...** 选择你要共享的视频文件夹（或手动输入路径）。
3. **启动服务**：点击 **启动服务器**。
4. **开始播放**：
   - **电脑端**：点击 **打开界面** 在浏览器中直接观看。
   - **手机/平板**：确保连接同一局域网 Wi-Fi，用相机扫描控制台上的 **二维码** 即可在移动端浏览器播放。

---

## ⚠️ 已知限制与提示

1. **编码兼容性**：受限于浏览器原生播放引擎的能力，部分特殊编码或封装格式可能无法在浏览器中直接播放。
2. **字幕支持**：当前版本暂不支持自动加载外挂独立字幕文件（`.srt`），将在后续版本中支持。
